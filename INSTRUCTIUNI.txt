RoomHub — CQRS + thin endpoints (cerinta 4)

1. Din radacina roomhub-starter ruleaza:
   unzip -o ~/Downloads/RoomHub_CQRS_etapa_4.zip -d .

2. Verifica:
   dotnet build src/RoomHub.Api/RoomHub.Api.csproj
   dotnet run --project src/RoomHub.Api --urls http://localhost:5000

3. Testeaza endpoint-urile HTTP. Nu sterge alte foldere si nu modifica fisierele .md automat.
4. Completeaza personal AI-LOG.md, DECISIONS.md si BUGS.md.
5. Dupa teste: git add src && git commit -m "Implement CQRS handlers and thin endpoints" && git push

NOTA: acest ZIP pornește de la etapa 1-3 și include R10 si R11 in Domain/Bookings/Booking.cs. Nu introduce EF Core (cerinta 5).
